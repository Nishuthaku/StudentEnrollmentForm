# Student Enrollment Form using JsonPowerDB

## 📄 Description

This is a micro project built using **HTML**, **JavaScript**, and **JsonPowerDB** as the backend database.  
The project allows users to **add or update student data** based on a unique Roll Number.  
It demonstrates the use of **JsonPowerDB's API** with a GUI built using HTML and JavaScript.

## 🚀 Benefits of using JsonPowerDB

- Simple to integrate: Minimal setup and easy API-based interaction.
- Lightweight: Ideal for front-end applications and micro-projects.
- Real-time data operations: Fast read/write access with no server-side code needed.
- Built-in security and token-based access
- No installation needed: Use directly with an internet connection.

---

## 📜 Features / Scope of Functionalities

- Add new student records (using Roll Number as key)
- Update existing records
- Form validation
- JsonPowerDB token-based API interaction
- Minimal UI with functional buttons: Save, Update, Reset

## ✅ Example (Demo)

- Enter Roll Number and student details, click "Save" to insert.
- Enter existing Roll Number and edit fields, then click "Update".
- Uses `PUT_BY_KEY`, `GET_BY_KEY`, and `SET/RESET` APIs of JsonPowerDB.
